# Changelog

## 1.0.0 (first public release)

- Engine: cubes fly in, settle and fly apart on a 2D canvas, with no dependencies.
- Motion timed by the clock: `duration`, `ease` (expo, cubic, back, elastic, linear), `stagger`, `spin`, and colour blending between icons.
- Eleven looks: flat, soft, clay, candy, paper, outline, pixel, glass, neon, wire, holo. One-ink `tint`, custom palettes in rgb or hex, icons with their own `colors`, `gap`, contact shadows.
- Front and isometric views, mouse tilt, `from` directions, `magnet`, `glow` (bloom) and `float` (idle motion).
- `show`, `clear`, `build` (part-built, 0–1), `explode`, `burst`, `scatter`, `set`, `destroy`.
- Helpers: `scroll` (scrub and trigger), `sequence`, `text` (a 5-row pixel font), `still`.
- 61 icons.
- Playground with 15 presets, every option and a copyable code box; twenty-eight recipes; an editor with image import (the image's own colours, up to 48 cells), My icons, and PNG, .js and JSON downloads.
- Docs for plain HTML, React, Next.js, Vue, Svelte, Framer, Webflow and WordPress.
- A Claude skill.
- Respects `prefers-reduced-motion`; pauses off-screen; draws only while something moves.
