Live clock

Content

The time in cubes. Each second the colon blinks and changed digits re-form.

setInterval(() => {
  const d = new Date(), pad = (n) => String(n).padStart(2, "0");
  stage.show(CubeIcons.text(pad(d.getHours()) + (d.getSeconds() % 2 ? " " : ":") + pad(d.getMinutes()), { color: "C" }));
}, 1000);

const look = { look: "soft", tint: "#3cff3c", glow: 0.8, float: 0.6, gap: 0.04 };
const hero = CubeIcons.stage(heroCanvas, { ...look, x: 0.72 });
const menu = CubeIcons.stage(menuCanvas, look);
hero.show("rocket");

button.addEventListener("click", () => {
  hero.burst();                                   // the object rushes at you and fades
  page.classList.add("open");                     // blur the page, fade the menu in (CSS)
  menu.scatter(90, { icon: "rocket" });           // loose cubes...
  setTimeout(() => menu.show("rocket"), 350);     // ...gather into the object
});
link.addEventListener("pointerenter", () => menu.show(link.dataset.icon));

Floating cubes

Interaction

Loose, glowing cubes drift across a section. Assemble gathers them into an icon, which keeps floating; Scatter lets them go again.

const stage = CubeIcons.stage(canvas, { look: "soft", tint: "#3cff3c", glow: 0.8, float: 0.7 });
stage.scatter(140, { icon: "bolt" });          // loose cubes drift across the canvas
button.onclick = () => stage.show("bolt");      // they gather into the icon, and keep floating
